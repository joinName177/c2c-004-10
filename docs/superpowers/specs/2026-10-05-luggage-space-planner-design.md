# 行李箱空间规划师设计说明

## 目标

构建一个完全在浏览器运行的 Vue 3 应用。用户输入行李箱尺寸、承重和物品清单后，应用生成可解释的三维装箱方案，以俯视图和侧视图展示位置，并给出超重、超体积、尺寸越界和未装入物品风险。所有数据仅保存在当前浏览器。

## 技术与工程约束

- Vue 3、TypeScript、Vite、Vitest；仅使用原生 CSS。
- 项目拥有独立 Git 仓库、README、Dockerfile、docker-compose.yml 和 Nginx 单页应用配置。
- 生产镜像使用 Node 构建、Nginx 托管，默认映射到宿主机端口 `8104`。
- 采用核心层、端口层、适配器层、界面层四层结构，依赖方向由外向内。
- 核心装箱算法不得依赖 Vue、DOM、localStorage 或 Canvas。

## 产品范围

### 行李箱配置

用户录入内部长、宽、高（厘米）和最大承重（千克）。输入必须为正数；无效数据在表单内明确提示，不进入装箱引擎。界面预置一个 55 cm 登机箱示例，方便首次打开即可体验。

### 物品清单

每件物品包含名称、类别、长宽高、重量、优先级和是否必须携带。支持新增、编辑、删除、筛选和快速切换“必须”。尺寸统一以厘米、重量统一以千克保存。

### 智能装箱

核心层实现确定性启发式三维装箱：

1. 过滤尺寸或重量非法的物品。
2. 为每件物品枚举允许的轴向旋转。
3. 使用候选角点策略，从箱体左下后方开始放置。
4. 候选位置按最低层、最靠后、最靠左排序；放置前检测边界和长方体相交。
5. 用优先级、是否必须、体积和重量形成不同方案的排序规则。

“精简版”优先必须物品和高优先级，主动保留约 20% 容量；“舒适版”在必须物品基础上追求均衡装载；“购物版”主动保留约 35% 容量和承重。算法输出已装物品坐标、旋转后尺寸、未装物品及原因、总体积和总重量。

### 风险检测

风险引擎独立计算承重利用率、体积利用率、单边越界、必需品遗漏、易碎品受压和重物位置偏高。风险按严重、警告、提示分级，并给出可操作建议。体积利用率只作总体指标，实际可放置性以空间碰撞结果为准。

### 可视化与打印

俯视图映射箱体长×宽，侧视图映射长×高。物品按类别着色，使用绝对定位矩形、编号和图例表现坐标与尺寸；选择物品时两个视图同步高亮。打印模式隐藏编辑控件，输出方案摘要、风险、清单、俯视图和侧视图。

### 方案对比

对比区同时展示三个方案的装入件数、重量、体积利用率、预留空间、风险数量和未装入物品。用户可以将任一方案设为当前方案并打印。

## 架构

- `src/core`：领域模型、校验、旋转与碰撞、装箱引擎、方案策略、风险检测。
- `src/ports`：规划快照仓储端口、打印端口。
- `src/adapters`：localStorage 仓储、浏览器打印适配器。
- `src/ui`：Vue 组件、组合式状态控制器和原生 CSS。

界面只通过应用控制器调用核心用例，不直接编写装箱规则。仓储通过端口注入，核心测试使用内存数据，不依赖浏览器。

## 状态与数据流

应用启动时从 localStorage 读取快照；不存在或解析失败时使用示例数据。用户编辑配置或物品后保存快照并标记方案为待更新；点击“重新规划”时一次生成三个方案并持久化选择结果。损坏的本地数据会被忽略并显示非阻塞提示。

## 交互与视觉

整体采用“旅行工作台”风格：温暖米白背景、深墨绿主色、橙色风险强调，桌面端以左侧配置/清单和右侧方案画布组成，移动端改为纵向卡片。所有按钮具备键盘焦点样式，表格在窄屏切换为卡片列表。

## 测试与验收

- 单元测试覆盖旋转去重、边界判断、碰撞检测、重量限制、必须物品优先、三种策略差异和风险等级。
- 组件级测试覆盖新增/删除物品、无效输入提示、方案切换和本地恢复。
- 验收需通过 `npm test`、`npm run build`，并人工检查桌面与移动布局、打印预览及 Docker 构建。

## 非目标

不实现真实物理形变、软包压缩、云同步、用户账号或服务端最优化求解。三维效果采用可解释的二维投影视图，不引入 WebGL。
